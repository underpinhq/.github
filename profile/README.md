# Underpin

To underpin something is to support it from below. Underpin is a set of open-source TypeScript packages that sit under the products built on them: React UI components, utilities, analytics helpers, and shared lint and release configs.

Everything lives in one monorepo, [underpinhq/underpin](https://github.com/underpinhq/underpin), and ships to npm under [`@underpin`](https://www.npmjs.com/org/underpin).
